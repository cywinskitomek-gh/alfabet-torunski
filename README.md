# Alfabet Toruński

Strona cyklu „Alfabet Toruński” – 22 krótkich utworów audiowizualnych Tomasza Cywińskiego o miejscach Torunia,
komponowanych algorytmicznie w OpenMusic.

Adres: https://cywinskitomek-gh.github.io/alfabet-torunski/

Zrealizowano w ramach stypendium Miasta Torunia w dziedzinie kultury.
